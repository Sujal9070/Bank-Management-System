# Bank Management System

A Java-based application that demonstrates common banking operations through an ATM-style workflow.

## Features

- Account creation
- ATM card and PIN login
- Cash deposits
- Cash withdrawals
- Fast cash withdrawals
- Balance enquiry
- Mini statement and transaction history
